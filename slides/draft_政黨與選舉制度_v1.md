### 🌸 Slide 2：集體選擇的理性困境：孔多塞悖論與阿羅不可能定理
- **版面型態**：左右雙欄卡片並列（`.columns`），呈現兩大公理化投票理論的呼應
- **左欄卡片（`.card`）**：
  - 徽章：`<span class="badge badge-pink">多數決的循環困境</span>`
  - 標題：**孔多塞悖論 (Condorcet Paradox, 1785)**
  - 核心機制：3 位選民對 3 方案進行兩兩表決：
    - 選民 1: $A \succ B \succ C$
    - 選民 2: $B \succ C \succ A$
    - 選民 3: $C \succ A \succ B$
    - 表決結果：$A$ 勝 $B$、$B$ 勝 $C$、$C$ 勝 $A$，形成循環多數：
      $$A \succ B \succ C \succ A \dots$$
  - 理論結論：**不存在穩定的孔多塞贏家，表決順序決定勝負（議程操縱）**。
- **右欄卡片（`.highlight-card`）**：
  - 徽章：`<span class="badge">公理化不可能證明</span>`
  - 標題：**阿羅不可能定理 (Arrow's Theorem, 1951)**
  - 核心條件：五項基本民主理性要件不可兼得：
    1. 無限制範圍 (U)
    2. 非專制性 (D)
    3. 巴烈圖最優 (P)
    4. 獨立於無關方案 (IIA)
    5. 偏好遞移性 (Transitivity)
  - 政治學意涵：**不存在客觀絕對的「總體民意」，選舉結果高度取決於「制度規則的選擇」**。

### 🌸 Slide 3：空間模型與政黨競爭：中位數選民定理 (MVT)
- **版面型態**：左右雙欄卡片並列（`.columns`），對比理性收斂模型與現實初選拉扯
- **左欄卡片（`.highlight-card`）**：
  - 徽章：`<span class="badge badge-pink">當斯模型 (Downs, 1957)</span>`
  - 標題：**中位數選民定理 (Median Voter Theorem)**
  - 基本假設：
    - 一維意識形態光譜（如左派 0 $\sim$ 右派 100）。
    - 選民皆具備單峰偏好（Single-Peaked），效用隨距離遞減。
    - 兩黨追求選票最大化，進行純粹多數決競爭。
  - 均衡預測：
    - 任何一方偏離中間皆會失利，最終兩黨政見必然**向心收斂（Centripetal Competition）於「中位數選民（立場 50）」**。
- **右欄卡片（`.card`）**：
  - 徽章：`<span class="badge">現實制度邊界</span>`
  - 標題：**模型限制與初選拉扯困境**
  - 理論破局因素：
    - **黨內初選拉扯**：參選人必須先討好深色黨員或極端意識形態支持者，深陷立場跳躍（Flip-flop）危機。
    - **多維議題空間**：臺灣同時存在「統獨國族認同」與「左右分配維度」，容易誘發混沌循環。
    - **第三勢力擠壓**：大黨過度中間化將促成兩翼真空，激發激進小黨策略性進場。

### 🌸 Slide 4：全球選舉制度兩大主軸：多數決制 (FPTP) vs 比例代表制 (PR)
- **版面型態**：左右雙欄卡片並列（`.columns`），系統性對比兩大經典選制哲學
- **左欄卡片（`.card`）**：
  - 徽章：`<span class="badge badge-pink">多數治理導向</span>`
  - 標題：**單一選區相對多數決 (FPTP / SMDP)**
  - 運作機制：選區規模 $M=1$，選民投一人，最高票（無需過半）者當選。
  - 代表國家：英國下議院、美國國會、加拿大、臺灣區域立委。
  - 優缺點分析：
    - **優點**：選區代表性明確、計票簡單、易產生一黨單獨過半之穩定內閣。
    - **缺點**：嚴重的「落選浪費票」、過度獎勵第一大黨（領先席次紅利）、加拉格爾指數 $LSq$ 偏高。
- **右欄卡片（`.highlight-card`）**：
  - 徽章：`<span class="badge">民意鏡像反映</span>`
  - 標題：**比例代表制 (Proportional Representation, PR)**
  - 運作機制：複數選區 $M>1$，政黨依得票比例分配席次（封閉式名單為主）。
  - 核心席次換算公式：
    - **最大餘數法 (LR)**：黑爾數額 $Q = V/M$、特羅普數額 $Q = \lfloor V/(M+1) \rfloor + 1$。
    - **最高均數法 (HA)**：漢狄法（除以 $1,2,3\dots$，偏大黨）、聖拉古法（除以 $1,3,5\dots$，中立）。
  - 政治效應：忠實反映社會多元聲音；通常形成多黨林立與聯合政府；需設「法定門檻（如 5%）」防碎化。

### 🌸 Slide 5：雙票制的兩大世界：並立制 (MMM) vs 聯立制 (MMP)
- **版面型態**：左右雙欄卡片並列（`.columns`），解構單一選區兩票制的本質差異
- **左欄卡片（`.card`）**：
  - 徽章：`<span class="badge badge-pink">兩票獨立計算</span>`
  - 標題：**並立制 (MMM / Parallel System)**
  - 核心算式：
    $$\text{國會總席次} = \text{區域當選席次} + \text{不分區政黨席次}$$
  - 實務代表：**中華民國臺灣（2008年起：73+34+6=113席）**、日本眾議院。
  - 政治效果：
    - **本質偏向多數決**：區域席次佔大宗，第一大黨席次率往往遠大於得票率。
    - **小黨生機渺茫**：小黨在單一選區幾無勝算，在不分區又受制於 5% 門檻，票席落差極大。
- **右欄卡片（`.highlight-card`）**：
  - 徽章：`<span class="badge">兩票折抵補償</span>`
  - 標題：**聯立制 (MMP / Compensatory System)**
  - 核心算式：
    $$\text{不分區應補席次} = \text{第二票政黨應得總席次} - \text{第一票區域已當選席次}$$
  - 實務代表：**德國聯邦議院**、紐西蘭眾議院。
  - 衍生關鍵機制：
    - **超額席次（Überhangmandate）**：當區域當選數大於政黨應得總額時破例保留。
    - **平準席次（Ausgleichsmandate）**：等比例擴增其他政黨席次，維繫純粹比例代表性。

### 🌸 Slide 6：杜瓦傑定律與量化指標：機械效應、心理效應與 ENP / LSq
- **版面型態**：左右雙欄卡片並列（`.columns`），左欄呈現經典機制推論，右欄呈現現代政治學量化指標
- **左欄卡片（`.card`）**：
  - 徽章：`<span class="badge badge-pink">經典因果法則</span>`
  - 標題：**杜瓦傑定律 (Duverger's Law, 1951)**
  - 核心命題：單一選區相對多數決有利於兩黨制；比例代表制有利於多黨制。
  - 雙重驅動機制：
    - **機械效應（選票 $\rightarrow$ 席次）**：贏者全拿造成「領先席次紅利」，全國性小黨選票在各區落選被系統性浪費。
    - **心理效應（選民與菁英認知）**：選民害怕浪費選票而進行「策略性投票（棄保）」；政治菁英與資源策略性進場湧向兩大黨。
- **右欄卡片（`.highlight-card`）**：
  - 徽章：`<span class="badge">量化政治指標</span>`
  - 標題：**有效政黨數 (ENP) 與票席不對稱指數 (LSq)**
  - **有效政黨數（拉克索-塔格佩拉指數）**：
    $$N_v = \frac{1}{\sum v_i^2} \quad,\quad N_s = \frac{1}{\sum s_i^2}$$
    （$N_v$ 為得票有效數，$N_s$ 為席次有效數。$N_v - N_s$ 反映選制的機械過濾強度）。
  - **加拉格爾不對稱指數（Gallagher Index）**：
    $$LSq = \sqrt{\frac{1}{2} \sum_{i=1}^{n} (v_i - s_i)^2}$$
    （以最小平方法量化衡量政黨得票率 $v_i$ 與席次率 $s_i$ 間的民意失真程度）。

### 🌸 Slide 7：薩托利政黨體系分類與聯合政府組成 (MWC)
- **版面型態**：左右雙欄卡片並列（`.columns`），剖析多黨國會的競爭本質與執政博弈
- **左欄卡片（`.card`）**：
  - 徽章：`<span class="badge badge-pink">政黨體系本體論</span>`
  - 標題：**薩托利政黨體系分類 (Sartori, 1976)**
  - 政黨計算雙重標準：必須具備「聯合執政潛力」或「阻礙勒索潛力」。
  - 核心分類（依意識形態距離）：
    - **兩黨制**：向心競爭（中位數選民取向）。
    - **溫和多黨制（3~5黨）**：意識形態距離窄，中間聯盟輪流執政（向心）。
    - **極化多黨制（5~6黨以上）**：具備**離心競爭、反體制政黨、雙邊反對勢力、中間被佔據、政見加價競標**等八大病理特徵。
- **右欄卡片（`.highlight-card`）**：
  - 徽章：`<span class="badge">組閣博弈理論</span>`
  - 標題：**聯合政府組成理論 (Coalition Theories)**
  - 辦公室導向（Office-Seeking）：
    - **甘姆森法則（Gamson's Law）**：內閣官職比例 $\approx$ 席次貢獻比例。
    - **最小獲勝聯合（MWC, Riker）**：席次過半，但抽離任何一黨即跌破 50%（杜絕多餘分贓）。
  - 政策導向（Policy-Seeking）：
    - **最小意識形態相鄰聯合（Axelrod）**：僅由光譜上相鄰連續的政黨結盟。
    - **少數政府（Strøm）**：在野黨相互牽制或委員會功能強大，執政黨以少數席次單獨執政。

### 🌸 Slide 8：臺灣選制改革經驗、法制規範與總結反思
- **版面型態**：左右雙欄卡片並列（`.columns`），左欄聚焦臺灣憲政選制變革軌跡，右欄聚焦公法規範與制度哲學終極省思
- **左欄卡片（`.card`）**：
  - 徽章：`<span class="badge badge-pink">臺灣選制變遷歷程</span>`
  - 標題：**告別 SNTV 邁向單一選區兩票並立制**
  - 舊制 SNTV 弊端（1992-2004）：
    - 同黨同室操戈、地方派系綁樁、買票賄選泛濫、高密度策略配票。
  - 2005 年第七次憲政改革：
    - 席次減半（225 $\rightarrow$ 113 席）、改採**單一選區兩票並立制 (MMM)**、不分區設 5% 門檻。
  - 改革後實證衝擊：
    - 席次有效政黨數 $N_s$ 自 3.2 以上驟降至 1.5~2.0，確立藍綠兩黨獨占體制；2008 年首度實施時 $LSq$ 飆至 15 創歷史失真新高。
- **右欄卡片（`.highlight-card`）**：
  - 徽章：`<span class="badge">法制規範與制度省思</span>`
  - 標題：**政黨法制與民主工程的終極取捨**
  - 臺灣政黨法制防線：
    - 《政黨法》：3% 競選費用補助款（每年每票 50 元，小黨維生線）、防範殭屍政黨淘汰機制。
    - 《政治獻金法》：個人/企業捐贈上限、許可專戶公開透明。
    - 立法院黨團機制：3 席成黨團、一個月協商冷凍期保障少數否決。
  - 結論與哲學反思：
    - **不存在完美無瑕的選舉制度**；所有制度設計皆是在**「多元代表性（Representation）」**與**「治理穩定性（Governability）」**之間進行權衡抉擇。規則一旦確立，即深刻形塑政治人物與選民的微觀理性行為。
